# MongoDB Practice Task – Products & Orders



## Collections

### Products Collection

The `products` collection contains product-related information such as:

- Product Name
- Category
- Price
- Stock

### Orders Collection

The `orders` collection contains order-related information such as:

- Product ID
- Quantity

## Topics Covered

This practice task covers:

- `$match`
- `$lookup`
- `$unwind`
- `$project`
- `$group`
- `$avg`
- `$multiply`
- `$sort`
- `$gt`
- `$gte`
- `$lt`
- `$lte`
- `$ne`
- `$or`
- `$and`
- `$in`
